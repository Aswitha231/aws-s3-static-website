## Project Description
This project demonstrates how to host a static website using Amazon Simple Storage Service (Amazon S3).

## Technologies Used
- Amazon Web Services (AWS)
- Amazon S3
- HTML
- CSS
- JavaScript

## Steps Performed
1. Created an S3 bucket.
2. Uploaded website files.
3. Enabled static website hosting.
4. Configured public access permissions.
5. Accessed the website using the S3 website endpoint.

## Result
Successfully hosted a static website using Amazon S3.
